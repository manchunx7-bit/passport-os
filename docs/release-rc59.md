# Passport OS 0.2.0-rc.59 · 媒体打开提速版

2026-11-11，本地社区候选，未发布。

## 本次调整

- 小智退出提速：断开 WebSocket 前先发一个 PING，服务器回的 PONG 会唤醒接收任务，不再等满 1 秒轮询。小智跳转城市电台或网易云时，等待旧应用退出的时间从约 0.98 秒降到约 0.1 秒。
- 小智退出期间保留最后一帧表情，不再闪一下“离线”状态。
- 首页进入 4 秒内不发起已到期的天气/空气 HTTPS 请求（手动刷新、换城市除外）。只是路过首页时，不会因为无法中断的 TLS 握手让下一次切换多等约 0.9 秒；首次进入仍为 15 秒后刷新。
- 网易云启动时，账号检查和歌单加载的优先级低于界面任务，首屏不再画到一半卡住等 HTTPS 握手。首屏完成从切换后约 1.1 秒降到约 0.3 秒；账号检查本身慢约 0.15 秒。
- 切换后首帧计时日志改为在目标界面装载后才开始计时，不再误记旧应用残留的一帧。

## 实测（串口模拟按键，同一设备）

| 场景 | rc.58 | rc.59 |
| --- | --- | --- |
| 小智（聆听中）→ 城市电台，按键到首屏画完 | 约 1.4 秒 | 约 0.5 秒 |
| 小智（聆听中）→ 网易云，按键到首屏画完 | 约 2 秒 | 约 0.4 秒 |
| 首页（天气到期）→ 城市电台 | 约 1.3 秒 | 约 0.5–0.7 秒 |

电台开始出声仍需约 1–1.5 秒，主要是电台流的网络连接时间，本次未改。另外试过切换期间临时锁定 CPU 160 MHz，实测首帧渲染没有变化，已撤回，没有放进本版本。

## 安装和测试

完整镜像 `*-full.bin` 用于全新安装，偏移 0x0；应用镜像 `*-app.bin` 用于相同分区布局的保留数据升级，偏移 0x10000。全新安装若执行 erase-flash 会清空所有数据，升级前先备份。不要将全新安装流程用于希望保留资料的设备。

本次完整主机回归、发布配置构建、分区和 SRAM 校验通过。首页天气调度测试新增“路过首页不请求、停留后再请求、手动刷新立即请求”的断言。

设备仅更新应用分区，8 MiB 读回确认所有非应用字节完整保留；rc.59 启动和堆检查通过，多轮切换无异常。以上计时为串口模拟按键，不等于实体按键和真人语音验收；原有功耗电流计、真人麦克风、长期提醒等人工验收边界不变。
