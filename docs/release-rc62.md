# Passport OS v0.2.0-rc.62 · 播客与听书、曜石工坊主题、真彩原图人像与交互升级

2026-11-25，社区发布用本地固件包；在 `v0.2.0-rc.61` 基础上集成跨平台构建说明、真彩人像与多项新功能。

## 更新内容

### 新增应用（共 15 款）

- **播客**：支持热门播客、今日主题、商业资讯、故事人文、相声评书与断点续播（`继续 · 上次节目`），配备 18 格实时 PCM 电平条、音量浮显与小智语音点播及定时停播。
- **听书**：提供热播有声书、悬疑推理、历史评书、名著科幻四个频道与最多 5 本书架断点持久化，支持 64K/32K 自动回退、免费章节连播与睡前定时。

### 第 5 套主题「曜石工坊」

- 保留原有 4 套主题（经典绿、旅行仪器、像素白、霓虹黑），新增深色多彩主题「曜石工坊」（`UI_THEME_STUDIO`）：石墨炭黑分层圆角卡片搭配信号橙、天空蓝、紫罗兰与翡翠绿识别色体系，覆盖首页、应用抽屉、设置、媒体播放器及小智界面。

### 首页真彩原图人像与手机设置页升级

- 融合 PR #4 并重构配网/人像设置页（`http://192.168.4.1`）：
  - **真彩原图（`PT37`）**：默认「原图」风格升级为 16 位真彩 RGB565 格式，跳过平滑模糊与 15 色量化分层，支持颜色保留度（默认 100%）与纯色背景抠除。
  - **5 套主题人像与质感效果**：主题人像调色板直接由固件主题枚举派生；选中单色主题时支持「点阵」「平涂」「平涂＋点阵」三种质感，并完全兼容旧版 `PT35`/`PT36` 人像文件。
  - **手机端交互优化**：裁剪框与「设备实效」预览并排紧凑布局，采用 GPU 硬件加速平移缩放与双指捏合，消除手机缩放卡顿。

### 小智 AI 语音控制与播报体验

- MCP 设备控制工具扩展至 25 项：新增语音修改首页姓名/签名、切换主题/熄屏时长/按键音、查询电量/城市天气/书架，以及播客与听书点播/定时停播。
- 扩大音频播放环形缓冲、提升解码任务优先级，并在活跃对话期间临时切换高性能 Wi-Fi，减少回复中途卡顿；未开始对话前居中显示操作提示。

### 性能、跨平台构建与其它改进

- 俄罗斯方块单对象按条带自绘、首页点阵时钟/像素图形按条带裁剪、`bsp_lvgl_unlock()` 即时唤醒显示任务，并增大 `input_disp` 任务栈，显著提升界面切换与重绘响应。
- 关闭低电量提示音（保留低电量屏幕提示与调暗），随身语音支持电脑端长按热键开麦。
- 合并 PR #3：新增 macOS / Linux / Windows 跨平台编译说明与 [安全刷机指南（中文）](safe-flashing.zh_CN.md) / [Safe Flashing Guide (EN)](safe-flashing.en.md)。

## 包内文件与烧录

- `FoloToy-AI-Passport-v0.2.0-rc.62-app.bin`：相同分区布局的现有 Passport OS 升级，偏移 **0x10000**。先备份，只写应用镜像，不勾选整片擦除，保留 Wi-Fi、个人资料、头像与随身名片。
- `FoloToy-AI-Passport-v0.2.0-rc.62-full.bin`：全新安装，偏移 **0x0**。选择 ESP32-C3、8 MB Flash、DIO、80 MHz。需要彻底清空时先备份，再整片擦除并烧录；Wi-Fi、身份、名片、设置和其他本地数据会被清除。
- `Passport-OS-v0.2.0-rc.62-source.zip`：对应源码快照，包含构建期修复脚本及第三方许可。
- `SHA256.txt`、`manifest.json`、`verification.json`：文件校验值、镜像信息和验证范围。

升级至本版后，若此前保存过旧版 15 色头像，可在设备「设置 → 手机设置」重新选图保存一次，即可在「原图」模式下切换为真彩 `PT37` 头像。
