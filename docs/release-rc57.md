# Passport OS 0.2.0-rc.57 · 社区候选测试版

日期：2026-11-08。适用 ESP32-C3 / 8 MiB Flash 的 FoloToy AI Passport。此包尚未公开发布，等待维护者实机验收。

## 本版内容

汇总当前维护源码：13 个应用卡片统一标题与图标、手机配网与名片、天气、电台、网易云音乐、小智和全局快捷对话、语音清单与重复提醒、AI 资讯、番茄钟与游戏等。保留三项待机优化：非音频前台熄屏串口 250 ms 轮询、小智熄屏表情 1 Hz、离线待机下次扫描至少 300 秒。版本由 rc.56 更新为 rc.57，用于区分本次公开配置候选构建。

使用 PASSPORT_PUBLIC_RELEASE=ON 构建，Muse 默认代理为空；不携带维护者 Wi-Fi、个人资料、设备身份或设备整片备份。外部服务仍需用户自行配网、绑定或满足服务要求。

## 包内文件

- `*-full.bin`：完整初始化镜像，烧录偏移 `0x0`。
- `*-app.bin`：应用镜像，偏移 `0x10000`；仅适合同分区布局且明确要保留资料的升级。
- `*-source.zip`：本包对应源码快照，含依赖锁文件。
- `manifest.json`、`SHA256.txt`、`source-files.sha256.json`：镜像与源码校验。
- `verification.json`：实际验证范围和结果。

## 全新安装

**全片擦除会清除 Wi-Fi、绑定/配置、名片、提醒、清单和其他本地资料。先保存自己的备份。** ESP32-C3 硬件 eFuse/MAC 不属于可擦除 Flash 数据。

安装 Python esptool 后，在命令行将 PORT 替换为实际串口，并在文件所在目录执行：

```text
python -m esptool --chip esp32c3 --port PORT erase-flash
python -m esptool --chip esp32c3 --port PORT write-flash 0x0 FoloToy-AI-Passport-v0.2.0-rc.57-full.bin
```

首次启动会初始化存储并进入配网页。按屏幕提示连接设备热点并完成手机配网；具体热点名称以设备显示为准。首次初始化可能比正常重启慢。

## 已知验收边界
